# Música con licencia

1. Obtén música instrumental **solo de fuentes autorizadas** cuya licencia permita uso comercial en redes sociales (nunca descargada de YouTube ni de sitios no autorizados).
2. Copia el archivo aquí (los audios no se suben a git).
3. Añade una entrada en `music_library.json` con su procedencia, licencia y restricciones.
4. Marca `commercial_use_verified` y `tiktok_use_verified` como `true` solo tras leer la licencia. Anota quién lo verificó y cuándo.

El control de calidad **rechaza** cualquier video cuya pista no esté verificada.
